## 2. 系統現況摘要

訪客服務機為獨立 Web 應用，部署於現場設備或區網伺服器，透過後端代理與 YSCP 對接，提供訪客現場操作。

### 2.1 主要功能

| 功能               | 說明                                                                       |
| ------------------ | -------------------------------------------------------------------------- |
| 訪客預約           | 選擇部門／被訪人，填寫訪客資料後建立 YSCP 預約；送出後顯示「等待內部確認」 |
| 訪客報到           | 以預約密碼或手機查詢；確認後同意訪客須知並完成簽到                         |
| 臨時外出／返回     | 簽退可選「臨時外出」；返回時於報到流程「確認返回」                         |
| 正式簽退           | 完成離場，並通知 YSCP                                                      |
| 出口開閘（選配）   | 出口 LPR 比對臨時外出／已離場車牌，且須在登記後時限內（預設 15 分鐘）開閘  |
| 首頁統計與訪客紀錄 | 目前在場／臨時外出／今日離場；紀錄可看全部與所有離場（跨日累積至手動重置） |

### 2.2 權責分工

| 項目                                     | 負責系統                    |
| ---------------------------------------- | --------------------------- |
| 預約審核、入場門禁／車牌時段權限         | **YSCP**                    |
| 現場預約／報到／簽退操作介面             | **YSOP**                    |
| 臨時外出與已離場名單（供出口開閘比對，含時限） | **YSOP 本機**               |
| 出口 LPR 辨識與事件推送                  | **YSCP** → 推送至 YSOP      |
| 出口繼電器開閘指令                       | **YSOP** 呼叫 YSCP 開閘 API |

說明：

- **入場**不由 YSOP 直接開閘；入口權限由 YSCP 依預約時段控管。
- **出場**採「先在服務機完成簽退／臨時外出 → 車輛於時限內至出口 LPR 再自動開閘」。

### 2.3 網路部署

- 服務可部署於**區域網路（LAN）**，供現場觸控機或區網裝置以瀏覽器存取。
- YSOP 需能連線至 YSCP（Artemis OpenAPI）。
- 若啟用出口開閘，YSCP 亦需能連線至 YSOP 的事件接收位址（Webhook）。
- 預設服務埠：**3010**。

## 3. 資料儲存現況與建議

### 3.1 設計原則

| 資料類型                             | 主要存放位置                         |
| ------------------------------------ | ------------------------------------ |
| 訪客主檔、預約、在廠狀態（系統來源） | **YSCP**                             |
| 現場操作所需的短期／本機狀態         | **YSOP 本機檔案**（無獨立資料庫）    |
| YSCP 連線金鑰與開閘設定              | 伺服器環境變數（`.env`，不上傳前端） |

預約時仍會將 Email、手機傳給 **YSCP**（YSCP 建立預約所需）；YSOP 本身不另建訪客通訊錄或長期個資檔。報到／簽退時以密碼或手機向 YSCP **即時查詢**，非以本機通訊錄為準。

### 3.2 本機目前存放內容

| 存放位置                   | 內容                                         | 用途                                 |
| -------------------------- | -------------------------------------------- | ------------------------------------ |
| `data/kiosk-presence.json` | 單一 `visits[]`（status：on_site／temp_out／departed；完整欄位＋時間戳） | 統計、訪客紀錄、出口開閘時限比對 |
| `data/kiosk-settings.json` | 跑馬燈、主題、是否顯示預約、logo 檔名        | 本機畫面設定                         |
| `data/kiosk-logo.*`        | 自訂公司 logo                                | 首頁顯示                             |
| 伺服器記憶體（重啟即失效） | 報到／簽退一次性操作憑證（約 10 分鐘）       | 避免前端直接帶預約 ID 操作           |

說明：主訪客資料仍以 YSCP 為準；本機檔案主要支援「臨時外出／離場開閘」與畫面設定，而非完整訪客資料庫。

### 3.3 現況特性（單機區網）

| 項目     | 說明                                                                                                     |
| -------- | -------------------------------------------------------------------------------------------------------- |
| 適合情境 | **一台服務機／一台主機**、區網使用                                                                       |
| 優點     | 架構單純、無資料庫維運、部署快速                                                                         |
| 限制     | 多台服務機無法自動共用「臨時外出／已離場」名單；程序重啟後，進行中的一次性操作憑證會失效（需重新查詢） |

### 3.4 儲存方式建議

| 方案                             | 適用情境             | 說明                                                            |
| -------------------------------- | -------------------- | --------------------------------------------------------------- |
| **A. 維持本機 JSON（建議預設）** | 單點服務機、區網     | 符合目前架構與開閘名單需求；維運成本最低                        |
| **B. 共用儲存／輕量資料庫**      | 多台服務機或需備援   | 將 presence 集中，避免各機名單不一致                   |
| **C. 長期報表獨立倉儲**          | 需跨日統計、稽核匯出 | 建議仍以 YSCP 為主資料源；YSOP 僅同步必要事件，避免重複保存個資 |

**已確認：** 採方案 **A（本機 JSON）**。首頁「今日離場」僅計當日；所有離場跨日累積，於 `/setting` 手動重置（清離場累計、取消臨時外出標記；**保留**在場完整資料；在場人數仍跟 YSCP）。

## 4. 現場流程說明（現況）

### 4.1 訪客預約

1. 選擇部門 → 被訪人
2. 填寫姓或名、Email、手機（建立 YSCP 預約所需）；公司、車牌、事由可選
3. **時段僅限當日**（開始／結束時間不可跨日）；跨多日預約請於 YSCP 建立
4. 送出後顯示等待內部確認
5. 預約階段**不需**同意訪客須知

### 4.2 訪客報到

1. 輸入預約密碼或手機（查詢時段約前 30～後 30 日，涵蓋提早預約）
2. 若為臨時外出中：
   - **當日返回**：可「確認返回」（不需再同意須知）
   - **跨日至翌日返回**：須再同意訪客須知後確認返回
3. 一般報到：同意訪客須知後完成報到
4. 成功畫面提示等候帶領

### 4.3 訪客簽退

1. 輸入密碼或手機
2. **目前在場**：可選臨時外出或正式簽退（跨日訪客當日離場請用臨時外出）
3. **臨時外出中**：僅可正式簽退；返回請走報到
4. 簽退／外出成功後提示「請於 N 分鐘內離場」（預設 15），**不顯示倒數**
5. 首頁「今日離場」僅計當日正式簽退；跨日離場見紀錄「全部／所有離場」

### 4.4 出口開閘（選配）

車輛至出口 LPR → YSCP 推送事件 → YSOP 比對臨時外出或已離場車牌，且登記時間在開閘時限內 → 開閘。

### 4.5 訪客須知與施工影片

| 規則         | 說明                                     |
| ------------ | ---------------------------------------- |
| 文字須知     | 報到前需閱讀並勾選同意（須捲閱至底部）   |
| 影片顯示條件 | **僅當來訪事由為「施工」時**顯示須知影片 |
| 跨日返回     | 臨時外出跨日翌日返回時，須再同意訪客須知；**施工**事由同樣播放影片 |
